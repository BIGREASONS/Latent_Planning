# LatentBench — When Geometry Misleads

## Research contribution
The project studies whether geometric reconstruction metrics adequately measure semantic fidelity in latent transition models.

## Final experimental scope
- Countdown
- Frozen TinyLlama/TinyLlama-1.1B-Chat-v1.0
- Linear
- MLP
- Transformer
- Seeds 42, 43, 44
- 9 architecture x seed conditions

## Key result
Under the evaluated TinyLlama–Countdown setting, geometric similarity remains high while True Action Semantic Gain is negative across all nine audited runs. Architecture-level differences in Oracle Gap are not statistically distinguishable under the three-seed design.
